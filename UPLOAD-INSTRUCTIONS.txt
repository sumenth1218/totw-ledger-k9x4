IMPORTANT — THESE CONTRACTS ARE PRESERVED:
- Dates & Enquiries data and workflow are unchanged.
- Crew Planner data and workflow are unchanged.
- Existing private client links remain valid.
- Existing crew links remain valid.
- Existing Firebase paths and records remain unchanged.

WHAT IS NEW IN v10:
- Each client now opens as one organised folder.
- The inside sidebar contains Overview, individual event names, Deliveries, Costs and Activity.
- Each event has one focused page with Event Details, Studio Plan and Shoot Record.
- Lists, boards, team readiness, check-in, checkout and card handover are attached to the event instead of competing as separate client-level tabs.
- The client Activity view keeps important milestones quiet and chronological.
- On mobile, the inside sidebar becomes a compact horizontal event switcher.

PRESERVED FROM v9:
- The selected private client link is now the only source of event cards inside a client workspace.
- Dates & Enquiries and Crew Planner can still supply the client directory, but they no longer create extra timeline, Lists & Boards, or client Shoot Operations cards.
- Matching crew shoots attach to the correct private-link event using stable link identifiers first, with a safe legacy date/name fallback.
- Spelling variants such as Mehndi, Mehendi and Mehandi reconcile without creating duplicate cards.
- Combined legacy labels such as “Haldi & Mehendi” or “Haldi & Sangeet” no longer appear as additional planning events.
- Legitimate same-day events saved in the client link remain separate.
- The wedding-level team assignment workspace is now consistently dark: crew cards, filters, dropdowns, event footers and action states have proper contrast.

- Dates & Enquiries logic

- Client or crew URLs
